## stm32-flasher 0.3.1: диагностика окружения

- `doctor`: сравнение окружения с паспортом выпуска, статусы OK/WARN/ERROR на RU/EN.
- `info`: SHA-256 запущенного `flash.cmd` для различения копий с одинаковой версией.
- Предупреждение, если Windows видит J-Link, но доступ через SEGGER Commander не подтверждён.

Для обновления замените все CMD-файлы рядом с прошивкой, включая новый `doctor.cmd`.
Doctor не подключается к MCU и не меняет настройки или драйверы. База его паспорта
остаётся 0.3.0; диагностика не подтверждает готовность платы и образа к прошивке.

## stm32-flasher 0.3.1: environment diagnostics

- `doctor`: compare the environment with the release baseline, with RU/EN OK/WARN/ERROR findings.
- `info`: SHA-256 of the launched `flash.cmd` to distinguish copies with the same version.
- A warning when Windows detects J-Link but access through SEGGER Commander is unconfirmed.

To upgrade, replace all CMD files beside the firmware, including the new `doctor.cmd`.
Doctor does not connect to the MCU or change settings or drivers. Its passport
baseline remains 0.3.0; diagnostics do not confirm board or image readiness.
