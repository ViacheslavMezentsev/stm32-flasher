## stm32-flasher 0.2.10: стабильность и безопасная проверка

Набор команд для прошивки STM32, резервного копирования, стирания Flash,
обзора окружения и очистки настроек. Основная логика остаётся в одном `flash.cmd`.

Главное:
- `-DryRun` проверяет локальный Intel HEX и SHA-256, показывает план без запуска
  утилит, опроса USB/MCU, сети и изменения файлов.
- Улучшены обнаружение программаторов, обработка тайм-аутов и выбор по явному
  серийному номеру. Исправлена передача путей с пробелами и кодов ошибок через CMD.
- История не перезаписывает последовательные сессии в одну секунду; исправлены
  ссылки из архивных отчётов. Индекс показывает последние 20 сессий, сохраняя старые файлы.
- Автоматические проверки Windows PowerShell 5.1 и PowerShell 7 запускаются в CI;
  результаты и длительности наборов сохраняются в логах.

Проверено на WeAct BluePill-Plus с 128 КиБ Flash: CubeProgrammer 2.19.0 со ST-Link
и J-Link, OpenOCD 0.12.0 со ST-Link, SEGGER Commander V8.32 с J-Link V9.60.
Перед стиранием сохранены и проверены копии, после восстановления все байты
совпали с исходными. Это проверка одной платы, не всей линейки STM32.

Ограничения: CubeProgrammer/J-Link не выполняет финальный reset; для сброса и
запуска используйте прямой движок `-Engine JLINK`. Одновременные операции
не блокируются. DryRun не проверяет совместимость прошивки с памятью конкретного MCU.

## stm32-flasher 0.2.10: stability and safe preview

Commands for STM32 flashing, backup, Flash erasure, environment information and
configuration cleanup. The core logic remains in a single `flash.cmd`.

Highlights:
- `-DryRun` validates local Intel HEX and SHA-256 and shows a plan without running
  tools, querying USB/MCU, accessing the network or modifying files.
- Improved probe discovery, timeout handling and explicit serial selection.
  Fixed quoted paths and error-code forwarding through CMD.
- History preserves sequential sessions within the same second and fixes archived
  report links. The index shows the latest 20 sessions without deleting older files.
- Windows PowerShell 5.1 and PowerShell 7 tests run in CI, with logged results
  and suite durations.

Tested on a 128 KiB WeAct BluePill-Plus: CubeProgrammer 2.19.0 with ST-Link and
J-Link, OpenOCD 0.12.0 with ST-Link, SEGGER Commander V8.32 with J-Link V9.60.
Backups were verified before erasure; all restored bytes matched the originals.
This covers one board, not the entire STM32 family.

Limitations: CubeProgrammer/J-Link does not perform a final reset; use the direct
`-Engine JLINK` engine for reset and start. Concurrent operations are not locked.
DryRun does not check firmware compatibility with the target MCU memory.
