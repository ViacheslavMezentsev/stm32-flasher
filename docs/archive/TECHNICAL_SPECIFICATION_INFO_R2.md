# ТЗ: перечисление ST-Link в info

При подготовке к публикации реальные серийники в примерах заменены синтетическими; требования сохранены.

Ревизия: 2. Дата: 2026-10-08. Статус: экспериментальная реализация.
Область: только обзор окружения `info.cmd`; не общее ТЗ всего stm32-flasher.

## Требования

1. Получать список через установленный CubeProgrammer, только если его `--help` содержит `stlink-only`. Использовать исключительно `-l stlink-only`; не применять `-l st`, `-l stlink`, `-c` или `st-info --probe` для базового обзора.
2. Перечисление не должно намеренно подключаться к MCU, записывать или стирать память, сохранять настройки, отчёты или историю. Поддержка опции проверяется по локальной справке производителя.
3. При отсутствии, сбое, неподдерживаемой опции или нераспознанном выводе пробовать следующую найденную установку, затем Windows USB. Каждое внешнее обращение ограничено 10 секундами ожидания процесса и 1 секундой завершения чтения вывода.
4. Разбирать только блоки `ST-Link Probe`, исключая J-Link и повторения в UART. Сохранять название платы, если оно доступно.
5. Подтверждённым для отображения считать номер из 24 шестнадцатеричных символов. Другие значения показывать как недоступный серийник и отдельный диагностический ID. Не выводить соответствие между Windows ID и прошлым serial по порядку элементов.
6. Показывать источник списка. При сообщении ошибки в распознанном выводе CubeProgrammer показывать предупреждение о возможной неполноте списка.
7. Не менять выбор программатора для прошивки, backup или erase; не менять версию и не выпускать релиз в рамках эксперимента.
8. При тайм-ауте J-Link показывать локализованное сообщение с пределом 10 секунд в разделе USB-программаторов, затем совет проверить USB и повторить `info.cmd`. Не трактовать тайм-аут как отсутствие всех программаторов; ST-Link и последующие разделы остаются видимыми. Другие ошибки не обозначать как тайм-аут.

## Приёмка

- Регрессия: четыре ST-Link, известный serial `444444444444444444444444`, имя NUCLEO, пустые имена, CRLF/LF, J-Link/UART не попадают в список ST-Link.
- Ошибка `DEV_CONNECT_ERR` с Windows ID не превращается в достоверный серийник.
- Проверены отсутствие CubeProgrammer, неподдерживаемый ключ, сбой запуска и резервное перечисление.
- Новые и существующие тесты проходят в PowerShell 5.1 и 7. Перед будущим выпуском обязательны полный локальный прогон и CI.
