# Каталог команд GitHub Pages

**Русский** | [English](README.en.md)

Статический справочник поведения 0.3.1. `commands.json` содержит RU/EN тексты
11 команд; `ci/build_site.py` собирает 24 HTML-страницы из общего шаблона.
`assets` содержит общий CSS и переключатель темы. Содержимое и навигация
работают без JavaScript, сервера и внешних библиотек. Скрипты MCU не запускаются.

## Проверка и предпросмотр

Из корня репозитория:

```powershell
python -B -X utf8 ci/test_site.py
python -B -X utf8 ci/build_site.py --output tests/.tmp-pages-preview
Start-Process tests/.tmp-pages-preview/index.html
```

`tests/Test-Pages.ps1` автоматически входит в обычный CI PS5.1/7. Проверяются
полнота по `bin/*.cmd`, RU/EN, маршруты, локальные ссылки/якоря, ресурсы,
отсутствие внешних скриптов и воспроизводимость сборки. Это не визуальная
проверка браузером и не аппаратный тест.

## Общий стиль STM32-сайтов

`assets/site.css` и `assets/theme.js` взяты из demo-stm32-skills: цвета
GitHub Primer, тёмная тема по умолчанию, круглая кнопка «тёмная → светлая →
системная». Ключ `demo-stm32-skills-theme` общий: сайты на
viacheslavmezentsev.github.io делят хранилище, поэтому выбор темы один для всех.
Нижний раздел CSS содержит нейтральные дополнения (язык, кнопки, выноски,
цвет `danger`); при изменении стиля переносите их в другие репозитории как есть.
Классы цвета: `offline` осмотр, `alt` настройка, `live` чтение MCU,
`view` состояние ядра, `danger` запись, стирание и удаление.

## Публикация

1. Владелец выбирает Settings → Pages → Build and deployment → Source:
   **GitHub Actions**. Эта настройка не выполняется скриптами репозитория.
2. Push рабочей ветки запускает обычный CI с Test-Pages, без публикации.
3. После успешного CI и `git land` workflow Pages собирает сайт из `main`,
   проверяет его и публикует только статический результат. Также доступен
   ручной запуск Pages с `main`. CI/Release workflows и архив утилиты не меняются.
4. Адрес: https://viacheslavmezentsev.github.io/stm32-flasher/ . До первого
   успешного Pages deployment сайт не считается опубликованным.

При изменении поведения обновляйте обе локали и номер описываемой версии
в шаблоне. Описание эффекта команды важнее краткости маршрута: erase не нужен
для обычной прошивки, check не возобновляет ядро, go не поддержан CubeProgrammer.
Проверяйте главную и длинную карточку на узком/широком экране, языки и темы.
