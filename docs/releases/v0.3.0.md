## stm32-flasher 0.3.0: настройки и управление платой

- Единый файл настроек `.flash.json` с переносом прежней конфигурации.
- `check`: сравнение памяти MCU с HEX без записи.
- `halt`, `go`, `reset`: остановка, продолжение и сброс с запуском.
- CMD-файлы находятся в `bin` репозитория и в корне релизного ZIP.
- Раздельные README RU/EN и ускоренный Windows CI с изолированными тестами.

Для обновления замените все CMD-файлы рядом с прошивкой. Старые настройки
переносятся при рабочем запуске или сохранении через `setup`.

`check` может оставить ядро остановленным. Поддержка команд зависит от движка;
остановка ядра не гарантирует остановку периферии и watchdog.

## stm32-flasher 0.3.0: configuration and board control

- Unified `.flash.json` settings with migration of legacy configuration.
- `check`: compare MCU memory with HEX without writing.
- `halt`, `go`, `reset`: halt, resume, and reset with execution.
- CMD files live in the repository's `bin` and the release ZIP root.
- Separate RU/EN READMEs and faster Windows CI with isolated tests.

To upgrade, replace all CMD files beside the firmware. Legacy settings migrate
during a working operation or when saving through `setup`.

`check` may leave the core halted. Command support depends on the engine;
halting the core does not guarantee that peripherals or watchdogs stop.
