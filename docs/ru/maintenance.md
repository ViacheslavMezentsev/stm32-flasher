# Работа с проектом

[English](../en/maintenance.md)

## Порядок работы с проектом

1. Прочитать [AGENTS](../../AGENTS.md), [README](../../README.md),
   [TODO](../../TODO.md), Unreleased в обоих CHANGELOG. Поведение сверять с
   [ТЗ](../TECHNICAL_SPECIFICATION.md) и [инструкцией](../user-guide.md).
2. Проверить ветку и незакоммиченные изменения. Новая работа — в
   `<агент>/<задача>` от актуального main; существующие правки сохранять.
3. Зафиксировать ожидаемое поведение, добавить воспроизводящий тест, сделать
   узкую правку в `flash.cmd`. Не дублировать код в обёртках. Версию выпуска
   согласовывать отдельно, не повышать автоматически.
4. Запустить [регрессии](../testing.md) в PS5.1/7 и проверку ТЗ. Аппаратные опыты
   требуют разрешения, проверенной копии всей затрагиваемой памяти, восстановления
   и проверки результата после опыта, в том числе неудачного.
5. Обновить TODO, RU/EN CHANGELOG и памятки. В ТЗ сохранять номера требований,
   историю, сценарии и матрицу; запланированный тест не отмечать как PASS.
6. Проверить diff и отсутствие личных данных. Подготовить согласованный
   подписанный Conventional Commit на английском. Не отключать подпись.
7. Владелец делает push рабочей ветки и проверяет CI, затем выполняет `git land`
   без PR. При невозможности fast-forward остановиться, не использовать force
   push или reset. Push, land, теги и релизы агенту требуют отдельного поручения.

Команды: [HOWTO](HOWTO.md).

Архитектурный контракт: один самодостаточный `bin/flash.cmd`, остальные CMD
только обёртки; обязательных внешних файлов логики нет. Поддерживаются Windows
PowerShell 5.1 и PowerShell 7, RU/EN. Общие и локальные проверки: [ci](../../ci/README.md).
CHANGELOG использует только Добавлено/Изменено/Исправлено; пустые категории
опускаются, после версии и даты в той же строке пишется краткий итог выпуска.

При завершении этапа указывайте проверенную текущую ветку и последовательность
следующих Git-команд. Push и land разделяйте проверкой успешного CI.

## Документы и каталоги

Корень: README, CHANGELOG, LICENSE, AGENTS, TODO и конфигурация Git.
README.md и README.en.md связаны текстовыми переключателями языков.
`bin` содержит самодостаточный `flash.cmd` и тонкие CMD-обёртки. В релизном ZIP
команды лежат в корне; для работы их копируют в папку с прошивкой.
`docs/ru` и `docs/en` — памятки участников. ТЗ, существующие user-guide и testing
остаются русскими; новые памятки, README и CHANGELOG обновляются в RU/EN вместе.
Локальные исследования не требуют перевода.

`tests/Test-*.ps1` — проверки без MCU; `tests/tools` — проверка ТЗ.
Локальные исследования: `docs/research/NN-name`; прогоны: `tests/manual/NN-name`.
Они игнорируются Git и не должны поставлять обязательные файлы для CI.
Пользовательский ZIP формируется по явному списку release workflow;
файлы разработки не попадают туда автоматически.
